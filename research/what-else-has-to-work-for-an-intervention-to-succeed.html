The conditions behind a successful intervention

An intervention package should be described before attributing success to one component. Evidence for a package is not evidence for every component in isolation.

Evidence & Evaluation · Editorial briefSecondary synthesis · Not peer reviewed · Sources credited below

Key takeaway

An intervention package should be described before attributing success to one component. Evidence for a package is not evidence for every component in isolation.

Evidence and context

An illustrative scenario is describing a livelihoods program as an asset transfer. That label might leave out training, temporary consumption support, coaching and the practical arrangements that helped participants use the asset.

Banerjee and colleagues evaluated an integrated approach to improving livelihoods in six randomized trials. The package combined several forms of support, and the study reported benefits extending beyond implementation. Because the package was evaluated together, its findings do not establish that any single component would produce the same result alone. Science, 2015

This matters when organisations try to learn from earlier programs. A concise description can be useful for navigation, but the underlying record needs enough detail to identify what was actually delivered.

Which elements were included? How were they sequenced? What support accompanied the main activity? Which elements changed? What resources and relationships were needed to deliver them?

The practical ambition is modest but important: let someone identify which parts of an earlier experience they intend to reproduce and which they are changing. That creates a clearer basis for learning from what happens next.

Implications for research and practice

An intervention package should be described before attributing success to one component. Evidence for a package is not evidence for every component in isolation.

Scope and limitations

This is a selective narrative brief based on the linked publications, not a systematic review or a new empirical study. Illustrative scenarios and practice implications are editorial analysis. Findings should be interpreted within the settings, methods and observation periods of their original sources.
