Preliminary MapToc research. These notes explain the denominators and limits of the figures shown on the homepage.

[2] Preliminary MapToc audit

MapToc's reported retrieval date is 21 August 2026. Funding and implementing organisation percentages use 914 activities. Location and result checks use the 636 activities for which full XML was retrieved. The five-country naming audit uses a different, seven-code scope and does not establish outcome-reporting rates across those countries.

The original exports and coding rules are not published here, so these findings cannot yet be independently reproduced. The datastore is a source system, not an independent verification of MapToc's percentages.

Code for IATI

[5] Interpreting IATI fields

A location does not necessarily identify a district. A result can represent an output, outcome, impact or another measure. Missing fields in an inspected public record are not evidence that a program had no outcomes, kept no internal evidence or wasted funding.
